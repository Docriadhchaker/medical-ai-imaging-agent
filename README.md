# Medical AI Imaging Agent

This project is a medical imaging diagnosis demo using Google Gemini and Streamlit.

It is designed for educational and research purposes:
- Upload an X-ray, CT, or MRI image
- The agent uses Gemini vision capabilities to describe findings
- It also generates a patient-friendly explanation

⚠️ Disclaimer: This tool is not a medical device and must not be used for real clinical decisions.
All outputs must be validated by qualified healthcare professionals.
